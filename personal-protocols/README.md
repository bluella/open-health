## Tags used in the notes

- **Tested** — confirmed on myself more than once; treat as a rule.
- **Personal** — works for me, probably not general advice.
- **Rethink** — an older observation I no longer fully trust; needs re-checking.

Each note has a **Sure** section (rules I follow) and a **Not sure** section (ideas to try or
observations that are still open). Ledgers use a table with a status column instead.
